# EXAMPLE JOB DESCRIPTION FOR DEMO

Job Title: Senior Frontend Engineer (AI Integration)
Company: SkillPath Corp

About the Role:
We are looking for a Senior Frontend Engineer to lead our next-gen AI dashboard development. You will be responsible for building high-performance, agentic user interfaces.

Requirements:
- 5+ years of experience with React.js and TypeScript.
- Deep expertise in Next.js 14+ (App Router, Server Components).
- Proficiency in Framer Motion for complex, high-fidelity UI animations.
- Experience with AI Orchestration tools like Vercel AI SDK or LangChain.js.
- Strong background in State Management using Zustand or TanStack Query.
- Experience with Tailwind CSS for rapid, design-driven development.

Nice to Have:
- Background in Python (FastAPI) for building AI-integrated backends.
- Knowledge of MongoDB for document-based data modeling.
- Experience building interactive "Thinking" states for LLM-driven apps.
